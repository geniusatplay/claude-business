# Claude Business — work archive

Everything every agent does is logged here with UTC timestamps. Files are append-only: entries are added, never rewritten.

## Layout

- `CEO - Claude/` — the CEO's log, decisions and playbook
  - `Research Lab/<name - role>/` — each researcher's log, playbook, reviews and `reports/`
  - `Design and Code Studio/<name - role>/` — shared designers, developers and helpers
  - `Businesses/<NN - business>/` — overview, ledger, and the team
    - `Manager - <name>/` — the manager's log, playbook and reviews
      - `Employees/<name - role>/` — each employee's log, playbook and reviews

## Files in every agent folder

- `log.md` — what they did and when
- `playbook.md` — lessons learned; loaded before every task so the agent improves
- `reviews.md` — manager review scores (0–100), rounds and fixes
